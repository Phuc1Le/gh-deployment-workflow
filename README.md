# Le Hong Phuc — Personal website

A short, static portfolio in a warm beige palette, built with HTML and CSS.

## Content

The five sections are introduction, experience, projects, leaderships, and hobbies.
Edit their text and links in `index.html`. Styling lives in `css/style.css`.
The Resume link opens `resume.pdf`; replace that file when updating the resume.

## Preview and deployment

Open `index.html` in a browser to preview locally. No installation or build is needed.
Pushing to `main` triggers `.github/workflows/deploy.yml` to deploy to GitHub Pages.

The site uses system fonts and has no scripts, animations, or external dependencies.
